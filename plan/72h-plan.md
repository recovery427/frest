# 72시간 실행 체크리스트

H+0은 대표님이 이 문서를 읽는 시각. 잠은 자야 하니 실질 가동은 약 40시간으로 잡았다.

---

## H+0 ~ H+4 — 팔 물건 만들기 (아웃리치 금지 구간)

포트폴리오 없이 DM 보내면 답장률이 1~2%로 떨어진다. 여기를 건너뛰면 뒤가 다 무너진다.

- [ ] `sales/offer.md` 가격 3줄 확인 → 바꿀 거면 지금 바꾼다 (나중에 바꾸면 견적이 꼬인다)
- [ ] **데모 포트폴리오 생성** — Claude에게 "데모 뽑아줘" (이미지 3컷 → 확인 후 영상)
- [ ] 판매 페이지 배포 → 링크 확보 (`site/index.html`)
- [ ] 입금 계좌 / 세금계산서 가능 여부 확정
- [ ] 크몽·숨고 서비스 등록 (`sales/outreach.md` C 복붙) ← **심사에 반나절 걸린다. 제일 먼저**
- [ ] 인스타 프로필 정리: 소개란에 "제품 사진 1장 → 24시간 광고영상" + 링크

## H+4 ~ H+8 — 아는 사람부터

전체 기대 계약의 절반이 여기서 나온다. 콜드 DM보다 먼저.

- [ ] 연락처·카톡 훑어서 **제품 파는 사람 20명** 리스트업 → `tracker.csv`
- [ ] `outreach.md` E 문구로 20건 발송 (문구 그대로 말고 원래 말투로)
- [ ] 과거 고객이 있으면 전원 연락. 재구매가 제일 싸게 딴 매출이다

## H+8 ~ H+14 — 타겟 리스트 만들기

- [ ] 올리브영 신상품 코너 / 무신사 뷰티 랭킹에서 **중소 브랜드 60곳** 수집
- [ ] 인스타에서 `#공동구매 #뷰티공구` 최근 게시물 → **셀러 50명** 수집
- [ ] 스마트스토어 뷰티 리뷰 300+ 상위 셀러 **40곳** 수집
- [ ] 각 브랜드 공식 인스타 / 문의 이메일 확보해서 `tracker.csv`에 정리
- [ ] 리스트에 최근 게시물 한 줄 메모 (DM 첫 줄 개인화에 쓴다)

## H+14 ~ H+20 — 1차 발송

- [ ] 인스타 DM **40건** (A-1 문구, 계정 제한 피해 나눠서)
- [ ] 이메일 **30건** (B 문구, 개별 발송)
- [ ] 셀러 커뮤니티 3곳 D 문구로 글 작성
- [ ] 발송 전부 `tracker.csv` 기록

**H+20 체크포인트** → 답장 3건 이상? 아니면 A-3 짧은 버전으로 갈아탄다.

---

## H+20 ~ H+28 — 휴식 + 자동 대응

- [ ] 자기 전 예약 발송 걸어둘 수 있으면 걸어둔다
- [ ] 잔다. 72시간 밤샘하면 H+50에 판단력이 무너진다

## H+28 ~ H+36 — 2차 발송 + 첫 상담

- [ ] 답장 온 건 **1시간 내 회신** (응답 속도가 계약률을 가장 크게 가른다)
- [ ] 인스타 DM **50건** 추가
- [ ] 이메일 **30건** 추가
- [ ] 상담 들어온 건 → `sales/quote-template.md`로 견적서 발송
- [ ] **첫 계약이 잡히면 즉시 제작 착수** (`ops/runbook.md`)

**H+36 체크포인트** → 상담 3건 미만이면 가격 문제가 아니라 포트폴리오 문제. 데모 3컷 더 뽑아서 링크 교체.

## H+36 ~ H+44 — 제작 + 3차 발송

- [ ] 수주 건 제작·납품 (건당 실작업 2~3시간)
- [ ] 인스타 DM **50건** 추가
- [ ] H+20에 답 없던 곳 팔로업 (한 번만)
- [ ] 납품 완료 건에서 **후기 요청** → 다음 아웃리치에 붙인다

## H+44 ~ H+52 — 휴식

- [ ] 잔다

## H+52 ~ H+64 — 클로징 구간

- [ ] 미결 상담 전부 정리. "이번 주 슬롯 2자리" 마감 압박 사용
- [ ] 남은 리스트 소진 (DM 40건 + 메일 30건)
- [ ] 계약 건 제작·납품 마무리

**H+56 체크포인트** → 계약 0건이면 100만원 접는다. 스타터 15만원 즉결가로 전환해서 건수부터 만든다.

## H+64 ~ H+72 — 마감 + 회수

- [ ] 잔금 청구·입금 확인
- [ ] 납품 완료 건 후기 요청
- [ ] `tracker.csv` 최종 정리 → 어떤 문구·채널이 먹혔는지 기록
- [ ] 결과 정산: 총 접촉 / 답장 / 상담 / 계약 / 매출

| 최소 접촉 | 하루 80건 |
| 기록 | 보낸 즉시 `tracker.csv` |
| 선금 | 입금 확인 전 제작 착수 금지 |

## 하지 말 것

- 판매 페이지 디자인 계속 만지기 (한 번 배포하고 손 뗀다)
- 안 팔린다고 가격 내리기 → 범위를 줄여라
- 무료 샘플 제작 → 데모로 대신한다
- 답 없는 곳 3번 이상 연락 → 차단당하고 계정만 상한다
