# 제작 SOP — 수주부터 납품까지

수주가 잡히면 이 순서대로만 한다. 실작업 2~3시간.
제작은 `ai-ad` 스킬이 다 한다. 사람이 할 일은 접수·컨펌·납품 세 개.

---

## Step 0. 착수 전 확인 (여기서 안 막히면 나중에 안 막힌다)

- [ ] **선금 입금 확인** — 안 됐으면 착수 금지
- [ ] **제품 누끼 이미지 1장** — 배경 투명 or 단색, 클로즈업 권장
- [ ] **모델 방향** — 원하는 톤 있으면 레퍼런스 1장, 없으면 이쪽에서 생성
- [ ] **납기 일시 확정** — "48시간"이 아니라 "O월 O일 O시"로 못 박아서 회신
- [ ] 제품 카테고리 확인 → 화장품이면 효능 문구 책임 소재 다시 안내

누끼가 없으면: +3만원 받고 `remove_background`로 처리한다.

---

## Step 1. 제작 (Claude에게 넘기는 구간)

Claude에게 이렇게 말한다.

```
ai-ad 스킬로 광고 만들어줘.
제품: [제품명 / 카테고리]
브랜드 톤: [간결하게]
납기: [일시]
[제품 누끼 이미지 첨부]
[모델 레퍼런스 첨부 — 없으면 생략]
```

Claude가 하는 일:
1. 제품 색감 추출 → 채도 10~15% 낮춘 톤으로 전체 컨셉 통일
2. GPT Image-2로 이미지 3컷 생성 (모델 단독 / 사용컷 / 제품 고스트샷)
3. **영상 전에 `get_cost`로 크레딧 확인하고 구성 설명 → 대표 승인 받음**
4. Seedance 2.0으로 5초 × 4클립 생성

**규칙: 영상 생성은 반드시 승인받고 돌린다.** 크레딧이 제일 많이 나가는 구간이라
컨셉이 어긋난 상태로 돌리면 그대로 손실이다.

---

## Step 2. 고객 컨펌 (이미지 단계에서 한 번)

영상까지 다 만들고 컨펌받으면 재작업 비용이 크다. **이미지 3컷에서 먼저 확인받는다.**

```
[담당자명] 님, 1차 시안 나왔습니다.

이 톤으로 영상 작업 들어가려고 하는데 방향 괜찮으실까요?
바꾸고 싶으신 부분 있으면 지금 말씀 주시면 반영해서 진행하겠습니다.

[이미지 3컷]
```

컨펌 오면 영상 착수. 여기서 하루 이상 답이 없으면 납기가 밀린다는 걸 미리 안내한다.

---

## Step 3. 후반 작업

- [ ] 4클립 이어붙이기 (5초 × 3 = 15초 구성, 남는 1클립은 대안컷)
- [ ] **훅 자막 삽입** — `hook-writer` 스킬로 후보 10개 뽑아서 제일 센 걸로
- [ ] 배경음 삽입 (저작권 프리, 상업적 이용 가능한 것만)
- [ ] 스탠다드 이상이면 1:1 리사이즈 (`reframe`)
- [ ] 워터마크·텍스트 잔여물 없는지 최종 확인

훅 자막은 그냥 넣는 게 아니라, 3개 편이면 **패턴을 다르게** 넣는다.
(결과부터 / 상식 깨기 / 타겟 지목 — A/B 테스트가 되게)

---

## Step 4. 납품

```
[담당자명] 님, [제품명] 광고 소재 납품드립니다.

■ 세로 숏폼 3편 (1080×1920)
■ 광고 이미지 6컷 원본
■ 후킹 문구 10안 (첨부)

[다운로드 링크]

숏폼은 훅을 다르게 3개 만들어뒀습니다. 세 개 다 돌려보시고
반응 좋은 쪽에 예산 몰아주시는 방식을 추천드려요.

수정 필요한 부분 있으면 편하게 말씀 주세요. 2회 포함되어 있습니다.
잔금은 [계좌]로 부탁드립니다.
```

- [ ] 다운로드 링크는 **최소 30일 유지** (재요청이 반드시 온다)
- [ ] 잔금 청구 같이 보낸다. 따로 보내면 잊힌다

---

## Step 5. 납품 후 (여기가 다음 매출)

- [ ] **후기 요청** — 납품 당일에. 다음 아웃리치 응답률을 가장 크게 올린다
```
혹시 결과물 괜찮으셨으면 짧게 후기 한 줄만 남겨주실 수 있을까요?
다음 작업 때 참고 자료로 쓰려고요.
```
- [ ] 결과물 1컷을 포트폴리오에 추가 (**고객 사용 허락 받고**)
- [ ] 2주 뒤 재구매 제안 리마인더 등록
- [ ] 실제 소모 크레딧을 `plan/unit-economics.md` 실측 기록란에 적는다

---

## 사고 대응

| 상황 | 대응 |
|---|---|
| 제품 각인·로고가 뭉개짐 | 해당 컷만 재생성. 제품 클로즈업 각도를 바꾼다 |
| 모델 얼굴이 컷마다 다름 | 레퍼런스 이미지 role을 다시 확인하고 재생성 |
| 크레딧 부족 | 이미지 컷 수를 줄이고 영상 클립을 우선한다. 영상이 상품이다 |
| 납기 못 맞춤 | **늦기 전에** 먼저 연락한다. 늦고 나서 하는 연락은 변명이 된다 |
| 고객이 실존 모델 요구 | 진행하지 않는다. 계약 전이면 거절, 계약 후면 전액 환불 |
