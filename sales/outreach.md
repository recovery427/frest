# 아웃리치 문구 — 복붙용

원칙 셋.
1. **첫 줄에서 광고 냄새가 나면 끝이다.** "안녕하세요 저희는~"으로 시작하지 않는다
2. **상대 얘기부터 한다.** 우리 소개는 두 번째 줄부터
3. **CTA는 하나.** "링크 보시고 관심 있으면 답장 주세요" 하나만

`[ ]`는 보내기 전에 반드시 채운다. 안 채우고 보내면 스팸으로 읽힌다.

---

## A. 인스타 DM

### A-1. 브랜드 공식계정용 (메인)
```
[브랜드명] [제품명] 릴스 잘 보고 있었습니다.
혹시 광고 소재 더 필요하시면 도움 될 것 같아서 연락드려요.

제품 사진 1장만 주시면 AI 모델로 세로 숏폼 광고를 24시간 안에 만들어 드립니다.
촬영·모델 섭외 없이 15만원부터고, 실제로 어떻게 나오는지 여기서 보실 수 있어요.
[링크]

지금 소재 필요하신 상황 아니면 편하게 무시하셔도 됩니다.
```

### A-2. 공동구매 셀러용 (단가 낮게, 결정 빠르게)
```
[제품명] 공구 준비 중이신 것 같아서요.

공구 시작 전에 숏폼 하나 걸어두면 반응이 다른데,
제품 사진 1장 주시면 내일까지 15초 광고 영상 만들어 드릴 수 있습니다. 15만원이고 내일 받아보세요.
샘플: [링크]
```

### A-3. 짧은 버전 (DM 길면 안 읽는 계정용)
```
[브랜드명] 광고 소재 만드시나요?
제품 사진 1장으로 숏폼 광고 24시간 안에 뽑아드립니다. 15만원부터요.
샘플 여기 있어요 → [링크]
```

## B. 이메일 (제휴·마케팅 담당)

**제목 후보 — 하나 골라서 쓴다**
- `[브랜드명] 광고 소재, 촬영 없이 24시간에 만드는 방법`
- `[브랜드명] 숏폼 소재 제안 (촬영 X, 24시간)`
- `광고 소재 3편, 이번 주 안에 필요하신가요`

**본문**
```
[담당자님/마케팅팀] 안녕하세요.

[브랜드명]의 [제품명] 광고 소재 관련해서 제안 하나 드리려고 메일 드립니다.

숏폼 광고는 결국 소재를 몇 개 돌려보느냐 싸움인데,
촬영으로 3편 만들려면 모델 섭외부터 2~3주에 수백만원이 듭니다.

저희는 제품 누끼 이미지 1장만 받아서 AI로 광고 영상을 만듭니다.
- 세로 숏폼 3편 + 이미지 6컷: 29만원
- 납기 48시간
- 모델 초상권·재계약 이슈 없음

실제 결과물은 여기서 보실 수 있습니다. [링크]

관심 있으시면 회신 주세요. 제품 이미지 받는 즉시 시안 보내드리겠습니다.
필요 없으시면 답장 안 주셔도 괜찮습니다.

[이름]
[연락처]
```

## C. 크몽 / 숨고 서비스 소개글

**제목**
```
제품 사진 1장으로 만드는 AI 광고 숏폼 | 촬영 없이 24시간 납품
```

**소개**
```
촬영 스튜디오 잡고, 모델 섭외하고, 일정 맞추다 보면 2~3주입니다.
제품 사진 한 장 주시면, 내일 광고 영상을 받으실 수 있습니다.

■ 이런 분께
- 광고 돌릴 소재가 부족한 스마트스토어·브랜드 운영자
- 촬영 예산은 부담되는데 영상은 필요한 1인 사업자
- 소재 A/B 테스트를 여러 개 돌려보고 싶은 마케터

■ 작업 방식
1. 제품 누끼 이미지 1장 전달
2. 컨셉·톤 협의 (10분)
3. 광고 이미지 시안 확인
4. 영상 제작 → 납품

■ 가격
- 스타터: 숏폼 1편 + 이미지 3컷 / 24시간 / 150,000원
- 스탠다드: 숏폼 3편 + 이미지 6컷 / 48시간 / 290,000원
- 브랜드 패키지: 숏폼 10편 + 전속 AI 모델 / 5일 / 890,000원

■ 포함
MP4 1080p 세로형, 자막, 배경음, 이미지 원본, 상업적 이용권

■ 주의
모든 인물은 AI 생성입니다. 실제 모델 촬영이 필요한 건은 진행이 어렵습니다.
화장품 효능·성분 표시광고 검수는 포함되지 않습니다.
```

## D. 셀러 커뮤니티 / 오픈카톡

홍보 금지방이 많다. **먼저 도움을 주고 나중에 판다.**

```
숏폼 소재 만드는 거 다들 어떻게 하시나요?

저는 요즘 AI로 뽑는데 제품 사진 1장이면 15초 영상까지 나오더라고요.
직접 만든 것 몇 개 올려요 → [링크]

만드는 방법 궁금하신 분 있으면 댓글 주세요, 아는 만큼 알려드릴게요.
```

문의가 오면 그때 DM으로 유료 상품을 안내한다. 방에서 바로 가격 얘기하면 강퇴당한다.

## E. 기존 인맥 (전환율 최고 — 여기부터 시작)

정식 문구를 쓰지 말고 원래 말투로 보낸다.

```
형/누나/대표님, 오랜만이에요.

요즘 AI로 광고 영상 만드는 거 하고 있는데,
혹시 주변에 제품 파는데 영상 소재 없어서 고생하는 분 계실까요?

제품 사진 1장이면 하루만에 숏폼 뽑아드려요. 15만원부터고요.
샘플 이거예요 [링크]

소개해주시면 커피 사드릴게요 ☕
```

## 답장 왔을 때 (여기서 대부분 놓친다)

**"얼마예요?"**
→ 가격만 답하지 않는다.
```
제품 몇 개, 영상 몇 편 필요하신지에 따라 다른데
1편이면 15만원, 3편이면 29만원입니다.

혹시 제품 어떤 거고 언제까지 필요하신지 알려주시면
딱 맞는 구성으로 정리해서 보내드릴게요.
```

**"샘플 하나만 만들어주실 수 있나요?"**
→ 무료 제작은 안 한다.
```
무료 시안은 어려워서 대신 만들어둔 결과물을 보여드릴게요. [링크]
결과물이 마음에 안 드시면 선금 환불해드리는 조건으로 진행하셔도 됩니다.
```

**"좀 더 생각해볼게요"**
→ 24시간 뒤 딱 한 번만 팔로업. 두 번은 안 한다.
```
지난번 말씀 주신 건 어떻게 진행하실지 정하셨을까요?
이번 주 제작 슬롯은 2자리 남았습니다. 필요하실 때 편하게 연락 주세요.
```

**읽씹**
→ 48시간 뒤 딱 한 번, 새로운 걸 들고 간다.
```
지난번 보내드린 건 참고만 하시고,
[브랜드명] 제품으로 만들면 이런 느낌일 것 같아서 하나 더 보내드려요. [이미지]
```

## 발송 관리

- 인스타 신규 계정은 **하루 DM 30~50건**이 한계. 넘기면 계정 제한 걸린다
- 이메일은 한 번에 대량 발송 금지. 개별 발송하거나 10건씩 나눈다
- `[브랜드명]`, `[제품명]`을 안 채운 문구는 응답률이 1/5로 떨어진다
- 보낸 건 전부 `tracker.csv`에 기록한다. 안 하면 누구한테 뭘 보냈는지 24시간 만에 꼬인다
