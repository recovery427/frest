# 반론 대응

원칙: **반박하지 않는다. 인정하고 조건을 바꿔서 다시 제안한다.**
가격을 깎아주지 않는다. 대신 범위를 줄인다.

---

### 1. "비싸요"
```
어떤 기준에서 비싸신지 여쭤봐도 될까요?

촬영으로 같은 걸 만들면 모델비만 100만원부터 시작해서요.
예산이 정해져 있으시면 1편 15만원짜리로 먼저 하나만 돌려보셔도 됩니다.
```
> 깎지 말고 스타터로 내려보낸다. 15만원은 대부분 결재 없이 결정 가능한 금액이다.

### 2. "AI라서 좀 그런데요"
```
그 걱정 많이들 하십니다. 그래서 결과물부터 보시는 게 빠를 것 같아요. [링크]

요즘은 오히려 실사보다 톤 컨트롤이 잘 돼서
올리브영 브랜드들도 상세페이지에 섞어 쓰는 추세입니다.
보시고 별로면 진행 안 하셔도 됩니다.
```

### 3. "제품이 그대로 나오나요?"
```
제품은 보내주신 이미지를 레퍼런스로 그대로 유지합니다.
패키지 각인, 로고, 색상 다 보존돼요.

다만 제품이 심하게 반사되는 재질이거나 텍스트가 아주 작으면
1차 시안에서 확인하고 조정합니다. 그래서 수정 횟수를 포함해 드립니다.
```

### 4. "저작권 문제 없나요?"
```
결과물의 상업적 이용권은 전부 넘겨드립니다. 광고 집행·SNS·상세페이지 다 가능합니다.
인물은 실존 인물이 아닌 생성 이미지라 초상권 이슈도 없습니다.

다만 화장품 효능·성분 표시광고 심의는 저희 범위 밖이라
문구는 브랜드 쪽에서 확인해주셔야 합니다.
```
> 이 마지막 문장을 꼭 넣는다. 화장품법 표시광고 책임을 대신 지면 안 된다.

### 5. "우리 모델 얼굴로 만들 수 있나요?"
```
실존 인물 얼굴은 진행하지 않습니다. 본인 동의가 있어도 리스크가 커서요.
대신 원하시는 이미지에 가까운 AI 모델을 만들어서 고정으로 계속 쓰실 수 있습니다.
브랜드 패키지에 그 전속 모델 생성이 포함돼 있어요.
```
> 예외 두지 말 것. 딥페이크 시비에 한 번 걸리면 사업이 끝난다.

### 6. "다른 데는 5만원이던데요"
```
그 가격대면 템플릿에 제품 사진만 얹는 방식일 가능성이 큽니다.
저희는 제품 색감 뽑아서 배경·조명까지 매번 새로 설계하고, 모델 일관성을 유지합니다.

비교해보시고 결정하셔도 돼요. 결과물은 여기 있습니다. [링크]
```

### 7. "지금은 예산이 없어요"
```
알겠습니다. 혹시 언제쯤 소재 필요하실지 알려주시면 그때 다시 연락드릴게요.
```
> 여기서 매달리지 않는다. 날짜만 받아서 `tracker.csv`에 적고 넘어간다.

### 8. "먼저 샘플 하나만 만들어주세요"
```
무료 시안은 안 하고 있어서요, 대신 만들어둔 결과물을 보여드릴게요. [링크]

정 불안하시면 스타터 15만원으로 먼저 1편 진행하시고,
1차 시안이 마음에 안 드시면 전액 환불해드리는 조건으로 하셔도 됩니다.
```

### 9. "회사 결재를 받아야 해서요"
```
그러시면 견적서 보내드릴게요. 결재 올리시기 좋게 정리해서 드리겠습니다.
언제까지 결정하시면 될까요?
```
> 즉시 견적서 발송. 결재 건은 72시간 안에 안 끝난다고 보고 기대치를 낮춰둔다.

### 10. "수정은 몇 번까지 되나요?"
```
스타터 1회, 스탠다드 2회입니다.
색감·자막·컷 순서 같은 조정은 횟수에 안 넣고 그냥 해드려요.
컨셉을 통째로 바꾸는 경우만 수정 1회로 계산합니다.
```

### 11. "얼마나 걸려요?"
```
스타터는 24시간, 3편짜리는 48시간입니다.
제품 이미지 주시는 시점부터 카운트하고요.
```
> 자신 없으면 늘려 부른다. 지킨 납기는 다음 계약을 만들고, 어긴 납기는 환불을 만든다.

### 12. 읽고 답이 없다
문구를 바꿔서 딱 한 번만 더. 두 번은 안 한다.
```
지난번 보내드린 건 참고만 하시고,
[브랜드명] 제품이면 이런 느낌일 것 같아서 하나 만들어봤어요. [이미지]

필요하실 때 편하게 연락 주세요.
```
