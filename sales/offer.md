# 상품 정의 — 팔 것을 정확히 못 박기

상담에서 말이 길어지는 이유는 상품이 안 정해져 있어서다. 아래 3개 밖으로 나가지 않는다.

---

## 패키지 3종

### 스타터 — 150,000원
**"일단 하나 돌려보고 싶은 분"**
- 세로 숏폼 **1편 (15초)**
- 광고 이미지 3컷 (모델 단독 / 사용컷 / 제품 단독)
- 자막 + 배경음 포함
- **납기 24시간**
- 수정 1회

### 스탠다드 — 290,000원 ⭐
**"광고 돌릴 소재가 필요한 분"**
- 세로 숏폼 **3편 (15초 × 3, 훅 다르게)**
- 광고 이미지 6컷
- 후킹 문구 10안 제공 (A/B 테스트용)
- 1:1 정사각 리사이즈 포함 (피드용)
- **납기 48시간**
- 수정 2회

### 브랜드 패키지 — 890,000원
**"이번 시즌 소재 한 번에 정리하는 분"**
- 세로 숏폼 **10편**
- 광고 이미지 20컷
- 전속 AI 모델 1인 생성 (얼굴 고정, 이후 재사용 가능)
- 상세페이지용 이미지 5컷 추가
- **납기 5일**
- 수정 무제한 (2주 내)

## 포함 / 불포함 (여기서 클레임 갈린다)

**포함**
- 기획·프롬프트 설계·생성·색보정·자막·음악
- 최종 파일 MP4 1080p + JPG 원본
- 상업적 이용권 (광고 집행, SNS, 상세페이지 전부 가능)

**불포함 — 견적서에 반드시 명시**
- 실제 사람 모델 촬영 (전부 AI 생성)
- 광고 계정 세팅·집행·운영
- 제품 누끼 이미지 제작 → 없으면 **+30,000원**
- 성분·효능 문구 검수 (화장품법 표시광고 책임은 광고주에게 있음)
- 3회 초과 컨셉 전면 변경 → 신규 건으로 재견적

## 대가 아니라 조건으로 파는 것

가격을 물으면 숫자만 던지지 말고 이 세 개를 먼저 말한다.

1. **24시간** — 촬영 잡으면 2~3주. 우리는 내일 받는다
2. **모델 리스크 0** — 모델 논란·재계약·초상권 분쟁이 없다. 얼굴은 우리가 만든 얼굴이다
3. **소재 여러 개** — 광고는 소재 개수 싸움인데, 촬영으로는 3편 뽑는 데 3배가 든다

## 타겟 (아무한테나 보내면 답장 안 온다)

우선순위 순.

1. **올리브영·무신사 입점 중소 K-뷰티 브랜드** — 마케팅 1인 체제, 소재 갈증 심함, 예산 있음
2. **스마트스토어 뷰티/건기식 상위 셀러** — 리뷰 300개 이상, 광고 집행 중인 곳
3. **인스타 공동구매 셀러 (팔로워 5천~5만)** — 결정 빠름, 단가는 스타터
4. **로컬 피부과·에스테틱·네일** — 지역 타겟 광고 수요, AI 모델 거부감 낮음
5. **크몽·숨고 영상 카테고리 인바운드** — 이미 사려는 사람들. 등록만 하면 됨

**피할 곳**: 대기업(결재 3주), 정부·공공(입찰), 이미 인하우스 영상팀 있는 곳.

## 결제 조건

- 스타터: **전액 선결제** (금액이 작아 분할 의미 없음)
- 스탠다드·브랜드: **선금 50% / 납품 후 잔금 50%**
- 선금 입금 확인 후 제작 착수. 예외 없음
- 세금계산서 발행 가능 여부는 사업자 상태에 맞게 미리 정해둘 것

## 절대 하지 말 것

- "AI라서 싸요"라고 먼저 말하지 않는다. 싸게 사려 들면 계속 깎인다. **빠르고 리스크가 없어서** 이 가격이다
- 무료 샘플 제작 안 한다. 데모 포트폴리오로 대신한다
- 납기를 자신 없으면 늘려 잡는다. 24시간 약속하고 어기면 그 고객은 끝이다
