# 견적서 양식

상담 후 **1시간 안에** 보낸다. 하루 지나면 열기 전에 잊힌다.

---

## 견적서 (복붙용)

```
────────────────────────────────
견 적 서
────────────────────────────────

수신: [브랜드명] [담당자명] 님
발신: [이름] / [연락처] / [이메일]
작성일: [YYYY-MM-DD]
유효기간: 작성일로부터 7일

■ 프로젝트
[브랜드명] [제품명] 광고 소재 제작

■ 구성
─────────────────────────────────────────────
항목                          수량      금액
─────────────────────────────────────────────
세로 숏폼 광고영상 (15초)      3편    290,000
광고 이미지                    6컷     (포함)
후킹 문구 A/B안               10안     (포함)
1:1 리사이즈                   3편     (포함)
제품 누끼 제작                 1건      30,000   ← 필요시만
─────────────────────────────────────────────
소계                                   320,000
부가세 (10%)                            32,000
─────────────────────────────────────────────
합계                                   352,000
─────────────────────────────────────────────

■ 납기
제품 이미지 및 선금 확인일로부터 48시간

■ 결제
선금 50% 입금 후 착수 / 납품 완료 후 잔금 50%
[은행명] [계좌번호] [예금주]

■ 산출물
MP4 1080×1920 (H.264), JPG 원본, 상업적 이용권 포함

■ 수정
2회 포함. 색감·자막·컷 순서 조정은 횟수에 포함하지 않음.
컨셉 전면 변경은 1회로 계산하며, 3회 초과 시 별도 견적.

■ 참고사항
- 영상 내 등장 인물은 전부 AI 생성이며 실존 인물이 아닙니다.
- 화장품 효능·성분 등 표시광고 관련 문구의 적법성 검토는 본 견적에 포함되지
  않으며, 최종 확인 책임은 광고주에게 있습니다.
- 실존 인물의 얼굴을 사용한 제작은 진행하지 않습니다.
- 선금 입금 후 착수 전 취소 시 전액 환불, 1차 시안 전달 후 취소 시 선금은
  환불되지 않습니다.
────────────────────────────────
```

## 견적 보낼 때 같이 쓰는 메일 문구

```
[담당자명] 님, 안녕하세요.

말씀 주신 [제품명] 건 견적서 정리해서 첨부드립니다.
숏폼 3편 + 이미지 6컷 구성으로 48시간 납기 기준입니다.

제품 누끼 이미지만 주시면 바로 착수 가능하고,
이번 주 제작 슬롯은 2자리 남아 있습니다.

구성이나 예산 조정 필요하시면 말씀 주세요. 맞춰서 다시 정리해드리겠습니다.

[이름]
```

## 체크리스트

발송 전:
- [ ] 브랜드명·담당자명 오타 확인 (여기 틀리면 신뢰가 한 번에 날아간다)
- [ ] 부가세 별도 표기 여부 확정
- [ ] 계좌번호 정확한지 재확인
- [ ] 유효기간 넣었는지 (마감 압박은 유효기간이 만든다)

계약 확정 후:
- [ ] 선금 입금 확인 → **확인 전 착수 금지**
- [ ] 제품 이미지·레퍼런스 수령
- [ ] 납기일시 명시해서 회신 ("O월 O일 O시까지 드리겠습니다")
- [ ] `ops/runbook.md` 진행
